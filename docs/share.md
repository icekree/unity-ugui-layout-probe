# Prepared sharing copy

Unity uGUI Layout Probe is a frozen experimental Python reference for explicit RectTransform geometry: CanvasScaler, hierarchy transforms, rotated/mirrored rectangles, ancestor clipping and overflow measurements. Seven original JSON/PNG scenes run without Unity or a game. Invalid inputs and unresolved parents remain UNKNOWN; static overflow is not a confirmed runtime defect. Native Unity parity has not been systematically established.

Code, tests, limitations and a bounded engineering case: https://github.com/icekree/unity-ugui-layout-probe

Concrete synthetic counterexamples, reproductions, reuse and citations are welcome. No ongoing development is promised.

This text is prepared only; it has not been posted to any community.
